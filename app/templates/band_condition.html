How It Works

Short summary of what this estimate uses and what it does not use.

1. Fixed reference stations define condition.

Only configured fixed stations build the long-term audibility baseline. This is the core signal used to decide whether the band is below normal, normal, or enhanced.

2. Mobile traffic adjusts congestion only.

Mobile stations are not used as the propagation baseline. Their traffic is used as a channel-load correction, because heavy mobile traffic can reduce effective audibility.

3. Confidence depends on history and coverage.

Confidence goes up when there are enough reference stations and enough baseline samples. It drops when data is sparse or when mobile congestion is unusually high.
