# TX RF

Dieses Ziel sendet das Paket uber das gewahlte Funkmodem.

Verwende es fur:

- lokale Digi-Pfade,
- Cross-Band,
- RF-Port-zu-Port-Weiterleitung.

Typische Form:

```text
Empfänger RF -> RF-Duplikatverzögerungsfilter -> RF-Digipeating-Pfadregel -> TX RF
```
