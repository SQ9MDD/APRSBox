# TX RF

This target sends the packet through the selected radio modem.

Use it for:

- local digi paths,
- cross-band forwarding,
- RF port-to-port forwarding.

Typical layout:

```text
Receiver RF -> RF Duplicate Delay Filter -> RF Digipeating Path Rule -> TX RF
```
