# TX APRS-IS

This target sends the packet to APRS-IS.

Use it for:

- iGate uplink,
- locally generated APRSBox traffic that must reach APRS-IS.

Important limitation:

- this target always keeps the mandatory `APRS-IS Uplink Safety Rule`.
