# TX RF

Este destino envia el paquete por el modem de radio seleccionado.

Usalo para:

- rutas digi locales,
- cross-band,
- reenvio entre puertos RF.

Esquema tipico:

```text
Receptor RF -> Filtro duplicado (retraso viscoso) -> Regla de trayectoria y protección DIGI -> TX RF
```
