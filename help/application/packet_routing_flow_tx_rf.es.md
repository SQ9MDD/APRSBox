# TX RF

Este destino envia el paquete por el modem de radio seleccionado.

Usalo para:

- rutas digi locales,
- cross-band,
- reenvio entre puertos RF.

Esquema tipico:

```text
Receptor RF -> Filtro RF de retardo de duplicados -> Regla de ruta de repetición RF -> TX RF
```
