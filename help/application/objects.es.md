# Creacion de objetos

Los objetos APRS permiten publicar manualmente informacion sobre puntos fijos o temporales en la red APRS. Pueden incluir, entre otros, repetidores, pasarelas, puntos de campo, ubicaciones de eventos, avisos u otros lugares relevantes para los usuarios de APRS.

Esta pantalla se utiliza para crear, editar y transmitir objetos APRS desde la aplicacion.

## Objetos de repetidor y QSY

Un caso especial de los objetos APRS son los objetos que describen repetidores y frecuencias QSY. Al crearlos, conviene seguir las reglas aceptadas de nombres y formato, porque muchos radios APRS pueden reconocer estos objetos y mostrarlos al usuario de forma conveniente.

La descripcion de las buenas practicas para estos objetos se encuentra en un documento aparte:

[Objetos de repetidor y QSY](../protocoll/repeaters_qsy.es.md)

## Notas practicas

- El nombre del objeto debe ser inequívoco en toda la red APRS-IS.
- Para objetos permanentes, se deben evitar nombres que puedan entrar facilmente en conflicto con objetos de otras regiones.
- Para objetos temporales, conviene usar nombres comprensibles para los usuarios locales.
- El contenido del comentario debe ser breve, concreto y util en la pantalla de una radio o de un cliente APRS.
- Los objetos transmitidos por radio deben emitirse con una frecuencia razonable para no ocupar el canal innecesariamente.
