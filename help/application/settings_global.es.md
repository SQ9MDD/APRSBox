# Ajustes globales

Este panel controla los valores generales de visualización, retención y registro. Los administradores y operadores pueden guardar cambios; los usuarios con acceso de lectura solo pueden consultar los valores actuales.

## Idioma y unidades

- `Idioma` selecciona el idioma de la interfaz web y de la ayuda contextual.
- `Unidades` selecciona valores métricos o imperiales donde la aplicación admite conversión.
- `Conjunto de iconos` selecciona el diseño clásico o moderno de los símbolos APRS.
- `Paleta de color` cambia los colores de la aplicación para todos los usuarios.

## Tráfico y registros de eventos

- `Retención del historial de tráfico` controla cuánto tiempo permanecen en la base de datos las tramas de ejecución. La visibilidad del mapa y de las estaciones utiliza esta misma ventana.
- `Nivel mínimo de registro almacenado` guarda el nivel elegido y todos los niveles más graves.
- `Habilitar registros DEBUG` permite entradas de diagnóstico detalladas. Conviene habilitarlas solo temporalmente porque aumentan el número de eventos.

## Visualización de cobertura

- `Opacidad de relleno de cobertura` se guarda globalmente y controla el interior de las áreas de cobertura del mapa.
- `Opacidad del contorno de cobertura` controla solo el borde y se guarda localmente en el navegador actual.
- `0%` oculta el relleno o el contorno correspondiente.

Use `Guardar ajustes globales` para aplicar los valores globales.
