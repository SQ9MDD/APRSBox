# TX RF

To cel nadający pakiet przez wskazany modem radiowy.

Używaj go:

- dla digi,
- dla cross-band,
- dla przekazywania między portami RF.

Typowy schemat:

```text
Odbiornik RF -> Filtr opóźnienia duplikatów RF -> Reguła ścieżki DIGI RF -> TX RF
```
