# TX APRS-IS

To cel wysyłający pakiet do APRS-IS.

Używaj go:

- dla iGate,
- dla lokalnie generowanych ramek APRSBox kierowanych do Internetu APRS.

Najważniejsze ograniczenie:

- ten cel zawsze utrzymuje obowiązkowy `Filtr ścisły`.
