# TX APRS-IS

Dieses Ziel sendet das Paket zu APRS-IS.

Verwende es fur:

- iGate-Uplink,
- lokal von APRSBox erzeugten Verkehr, der APRS-IS erreichen soll.

Wichtige Einschränkung:

- dieses Ziel behält immer die verpflichtende `APRS-IS-Uplink-Sicherheitsregel`.
